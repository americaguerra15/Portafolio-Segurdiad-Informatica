Executive Summary

El presente reporte documenta una evaluación de seguridad realizada sobre el servidor vulnerable “My File Server 1”. Durante la auditoría se identificaron múltiples vulnerabilidades críticas relacionadas con autenticación, control de acceso, exposición de información sensible y escalada de privilegios.

La explotación exitosa permitió obtener acceso inicial mediante FTP, persistencia a través de SSH y posteriormente privilegios de administrador utilizando la vulnerabilidad Dirty COW (CVE-2016-5195).

Alcance

  • Objetivo: Máquina virtual "My File Server 1"
  • IP identificada: 192.168.56.102
  • Servicios evaluados: HTTP, FTP, SSH, SMB, NFS y RPCbind
  • Metodología aplicada: Pentesting Black Box

Metodología Aplicada

La evaluación de seguridad se realizó bajo el estándar PTES utilizando un enfoque de caja negra, simulando el comportamiento de un atacante externo.

Fase de Reconocimiento

Se utilizó la herramienta netdiscover para identificar los dispositivos activos dentro de la red local y localizar el servidor objetivo.

Enumeración

Durante la enumeración se identificaron múltiples servicios expuestos, incluyendo FTP, SSH, SMB y HTTP.

También se descubrió un archivo readme.txt accesible públicamente que contenía credenciales en texto claro.

Imagen 3: Enumeración web con Nikto.

Explotación

Utilizando las credenciales encontradas, se logró acceso exitoso al servicio FTP del servidor objetivo.

Imagen 5: Acceso exitoso al servicio FTP.

Escalada de Privilegios

Posteriormente se generaron llaves SSH para mantener persistencia dentro del servidor.

Finalmente se explotó la vulnerabilidad Dirty COW para obtener privilegios root sobre el sistema.

Imagen 6: Generación de llaves SSH.

Imagen 7: Explotación de Dirty COW.

Análisis de Impacto

  • Confidencialidad: Impacto total.
  • Integridad: Impacto total.
  • Autenticación: Comprometida.
  • Disponibilidad: Riesgo crítico.

Recomendaciones

  • Eliminar archivos sensibles públicos.
  • Implementar contraseñas robustas.
  • Reemplazar FTP por SFTP.
  • Actualizar el kernel de Linux.
  • Aplicar principio de menor privilegio.
